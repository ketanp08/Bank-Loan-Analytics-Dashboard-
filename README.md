# 🏦 Bank Loan Analytics Dashboard | Power BI

## 📌 Project Overview

The **Bank Loan Analytics Dashboard** is an interactive Power BI project designed to analyze bank loan applications, funded amounts, loan repayments, borrower performance, and credit risk.

The main objective of this project is to transform raw loan data into meaningful business insights that help financial institutions understand loan performance, identify risky loans, monitor repayments, and make better lending decisions.

The report contains two interactive pages:
- **Summary Dashboard**
- **Overview Dashboard**

## 🎯 Project Objectives

- Analyze total loan applications and funded amounts.
- Monitor loan repayment and collection performance.
- Identify good loans and bad loans.
- Analyze loan status and borrower risk.
- Compare interest rates and Debt-to-Income (DTI) ratios.
- Understand monthly loan application trends.
- Analyze loan distribution across different US states.
- Evaluate loan terms and homeownership categories.

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Measures and KPI calculations.
- **Data Visualization** – Charts, cards, donut charts, and geographical maps.

### 2. Overview Dashboard

The Overview page focuses on loan application trends and geographical distribution.

**Visualizations Included:**

1. Monthly Loan Applications – Analyzes application trends from January to December.
2. Loan Applications by State – Displays geographical distribution of loan applications across the United States.
3. Loan Applications by Term – Compares 36-month and 60-month loan terms.
4. Loan Applications by Home Ownership – Analyzes borrowers based on Rent, Mortgage, Own, and Other categories.

**Loan Term Analysis:**
- 36 Months: 60.05%
- 60 Months: 39.95%

**Home Ownership Analysis:**
- Rent: 1,545 applications
- Mortgage: 1,037 applications
- Own: 179 applications
- Other: 10 applications

## 💡 Key Business Insights

1. A total of 2,771 loan applications were recorded.
2. Good loans account for 79.57% of total applications, while bad loans account for 20.43%.
3. The total funded amount is $37.0 million, while the amount received is $41.3 million.
4. Fully Paid loans represent the largest share of loan applications.
5. Charged Off loans show a significant repayment gap, with $7.4M funded compared to $4.3M received.
6. December recorded the highest monthly loan applications at 313.
7. February recorded the lowest monthly loan applications at 177.
8. 36-month loans account for approximately 60% of applications.
9. Borrowers in the Rent category represent the highest number of applications.
10. The average interest rate across all loan applications is 15.74%.
